# Legacy wallet notes (pre-0.22)

These notes describe the wallet adapter as it behaved before the 0.22 split.
They are kept only until every integrator has moved to the plugin API.

## Note 1: historical behaviour

Before 0.22 the adapter owned the connection, which meant note 1 could only be applied by editing the adapter itself.

- the provider was resolved lazily, once per call site
- the sign-in payload was assembled by the caller
- errors surfaced as plain strings

Migration: move the call site onto the plugin, then delete the branch that handles the missing provider.
